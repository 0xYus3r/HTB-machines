
## 📝 Personal Notes

This repository is maintained as part of my personal learning journey in cybersecurity. Each writeup represents a challenge overcome and an opportunity for professional growth.

## 🎯 Objective

This repository aims to:
- Document attack methodologies and exploitation techniques
- Share enumeration and privilege escalation methods
- Create a learning resource for the cybersecurity community
- Help new penetration testers develop their skills

## 📖 Writeup Content

Each writeup follows a standard structure:

1. **Information Gathering**: Port scanning, service identification
2. **Vulnerability Analysis**: Searching for known vulnerabilities
3. **Initial Access**: Initial exploitation to gain access
4. **Privilege Escalation**: Escalating to administrative rights
5. **Post-Exploitation**: Post-compromise analysis
6. **Flag Capture**: Capturing User and Root flags
